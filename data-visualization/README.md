# Data Visualization

Trabalhos da disciplina de Data Visualization — MBA em Engenharia de Dados,
Universidade Presbiteriana Mackenzie.

Os dashboards foram construídos no Tableau e estão publicados no Tableau Public.
Arquivos `.twbx` não são versionados aqui porque os visuais dependem da base e
ficam desatualizados fora da plataforma.
