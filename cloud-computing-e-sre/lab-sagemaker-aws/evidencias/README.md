# Evidências do laboratório

Esta pasta contém o [PDF final da atividade](Entrega_LAB_MBA.pdf), exportado da campanha HTML **Organic Breakfast Cereals**.

O documento tem três páginas e apresenta a campanha de marketing com as duas imagens, as mensagens personalizadas, os benefícios do produto e os depoimentos ilustrativos.

As imagens utilizadas na campanha foram produzidas **fora do Amazon Bedrock**, pois o modelo Nova Canvas não estava disponível no ambiente do workshop. A produção das imagens não representa uma execução do Nova Canvas na AWS.

> **Privacidade:** antes de incluir outras evidências do console AWS neste repositório público, oculte identificadores de conta, credenciais, tokens, ARNs sensíveis e dados pessoais.
